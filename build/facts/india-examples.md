## Classification basics
- **[confirmed] F01** MDR 2017 sorts devices into four risk classes: Class A (low risk), Class B (low-moderate), Class C (moderate-high), Class D (high). Classes A/B are licensed by the State Licensing Authority (Form MD-5), Classes C/D by CDSCO/CLA (Form MD-9).  
  Source: An Overview of Classification of Medical Devices by CDSCO (Corpseed) <https://corpseed.com/knowledge-centre/classification-of-medical-devices-by-cdsco-in-india> — Note: Agreed by Corpseed, Freyr, RegDesk and Bhatt & Joshi summaries; mirrors First Schedule of MDR 2017.

## Class A examples
- **[likely] F02** Class A examples cited for India: elastic bandages, hot-water bags, (mercury/aneroid) sphygmomanometers, digital/clinical thermometers, non-sterile examination gloves.  
  Source: Examples of medical device classifications (Operon Strategist) <https://operonstrategist.com/examples-of-medical-device-classifications/> — Note: Search-result text only (page egress-blocked). 'Digital thermometer' was one of the 4 devices notified in Dec 2018 and classified Class A by CDSCO; verify against the CDSCO merged classification list of 15 Oct 2025 (https://www.cdsco.gov.in/opencms/resources/UploadCDSCOWeb/2018/UploadPublic_NoticesFiles/MDmergeclassification15oct25.pdf).

## Class B examples
- **[likely] F03** Class B examples cited for India: non-invasive blood-pressure monitors, hearing aids, hypodermic needles and syringes, sterile surgical gloves, contact lenses, wheelchairs (powered), electric massagers for physiotherapy.  
  Source: CDSCO classification of medical devices 2026 update (Agile Regulatory) <https://www.agileregulatory.com/blogs/cdsco-classification-of-medical-devices-2026-update> — Note: Consultancy summaries (Agile Regulatory, Corpseed, Operon) agree on BP monitor, hearing aid, syringe and gloves = Class B. Wheelchair is listed Class B by Operon but manual (non-active) wheelchairs may be Class A in the CDSCO rehabilitation list; contact lens = Class B is from memory (EU rule 5 analogue). Verify each in the CDSCO merged list.

## Class C examples
- **[likely] F04** Class C examples cited for India: infusion pumps, ICU ventilators, haemodialysis machines, X-ray and MRI systems, orthopaedic (hip/knee) implants, urinary/cardiac diagnostic catheters, glucometers (self-test IVD).  
  Source: An Overview of Classification of Medical Devices by CDSCO (Corpseed) <https://corpseed.com/knowledge-centre/classification-of-medical-devices-by-cdsco-in-india> — Note: Infusion pump, X-ray, MRI = Class C confirmed in search text. Ventilator, dialysis machine, orthopaedic implants, catheters = Class C from memory of CDSCO specialty lists; Corpseed text puts 'artificial joints' in Class D, so give both. Glucometer: Operon says Class C (IVD self-test), another summary says Class B.

## Class D examples
- **[likely] F05** Class D examples cited for India: heart valves, implantable pacemakers, coronary (drug-eluting) stents, intra-uterine devices, devices in contact with the central nervous system or central circulatory system.  
  Source: An Overview of Classification of Medical Devices by CDSCO (Corpseed) <https://corpseed.com/knowledge-centre/classification-of-medical-devices-by-cdsco-in-india> — Note: Heart valves and implanted pacemakers = Class D appear in search text. ## Pulse oximeter class
- **[unverified] F07** Pulse oximeter: no CDSCO class could be verified in search text; under First Schedule Rule 10 an active device monitoring vital physiological parameters whose variation could cause immediate danger is Class C, so pulse oximeters are generally treated as Class C in India (US FDA: Class II).

## Wearable gait sensor + app (analysis)
- **[likely] F11** A wearable gait sensor with a vibration cue and smartphone app would be an active device plus software: under the CDSCO SaMD approach, software that gives real-time patient parameters but no diagnosis is Class B (example: home-use ECG display software); Class A if it only does retrospective data analysis; Class C if it informs diagnosis/treatment.  
  Source: SaMD Regulation in India: CDSCO Classification (Class A-D) (Freyr) <https://www.freyrsolutions.com/blog/samd-regulation-in-india-cdsco-classification-class-a-d-registration-requirements-emerging-market-strategy> — Note: CDSCO uses the IMDRF SaMD definition. Hardware sensor is an active monitoring device (Rule 10 -> Class B unless vital-parameter danger -> Class C). Class B = state licence (MD-5) with notified-body audit; Class A = online registration only.

## MD-5 timeline
- **[likely] F22** Typical Class A/B licensing path: 4-5 months from application to final MD-5 licence, including notified-body audit; certification from a CDSCO-registered notified body / QMS audit is required before the licence.

## Parliamentary panel 2025
- **[confirmed] F25** The Department-related Parliamentary Standing Committee on Health's 170th report (16 March 2025, action-taken on its 163rd report) said CDSCO delays, inconsistent timelines and opaque licensing had pushed device makers to relocate to Vietnam and Malaysia, and recommended a fully digitised, trackable, time-bound licensing system, a single comprehensive query, and time-bound conditional approval (45 days).  
  Source: House panel flags licensing delays forcing medical device firms abroad (Business Standard) <https://www.business-standard.com/health/house-panel-flags-licensing-delays-forcing-medical-device-firms-abroad-125031300999_1.html> — Note: Business Standard, Medical Dialogues (45-day conditional licensing headline), BioVoice and Digital Health News all report it.

- **[likely] F34** In March 2020 CDSCO issued an order exempting ventilators from regulatory requirements/certification during the COVID emergency, so pandemic ventilators (e.g., AgVa) were produced under exemption rather than full licensure.

- **[likely] F51** The Embrace infant warmer (Stanford d.school origin) launched in April 2011 in Karnataka; heated ~30 minutes it keeps a newborn at clinical temperature for up to 6 hours; India chosen first because of ~26 million births/year.  
  Source: Portable warmer by students helping premature babies survive (Business Today) <https://www.businesstoday.in/story/portable-warmer-by-students-helping-premature-babies-survive/1/201084.html> — Note: An effectiveness trial is registered as ISRCTN19875148. Indian regulatory status not found.

## Jaipur Foot
- **[likely] F52** BMVSS (Jaipur Foot), founded 1975, has fitted over 2 million people with free limbs/aids through 23 Indian branches and camps in 40+ countries.  
  Source: Jaipur Foot / BMVSS <https://www.jaipurfoot.org/home/> — Note: Patrika (2024) says 'over 1 million across 44 countries' - give the lower figure if unsure.

## MedTech Mitra
- **[confirmed] F53** MedTech Mitra: ICMR with CDSCO, under NITI Aayog guidance, runs a portal (medtechmitra.icmr.org.in) offering innovators hand-holding on clinical evaluation, regulatory facilitation and product uptake; coordinated by ICMR's Medical Device and Diagnostics Mission Secretariat.  
  Source: About MedTech Mitra (ICMR) <https://medtechmitra.icmr.org.in/about> — Note: Official page (text via search). Launch date (memory: Dec 2023) unverified.

## BIS standards count
- **[confirmed] F54** BIS has 1,700+ Indian Standards for the medical sector, about 1,200 specific to medical devices, and announced on 25 Nov 2024 that standards for 214 critical medical devices (identified with the Department of Pharmaceuticals under the National Medical Devices Policy 2023) would be completed by Dec 2025.  
  Source: Bureau of Indian Standards to develop standards for 214 critical medical devices by December 2025 (BioVoice) <https://biovoicenews.com/bureau-of-indian-standards-to-develop-standards-for-214-critical-medical-devices-by-december-2025/> — Note: BioVoice, BioSpectrum, Sakshi Post and Corpseed agree on 214 and Dec 2025; 1,700/1,200 figures from the same PIB-derived text.

## Class A registration route
- **[likely] F55** Class A (non-sterile, non-measuring) devices need only online registration on CDSCO's portal; Class A sterile/measuring and Class B need an MD-5 licence from the State Licensing Authority with a notified-body QMS audit.  
  Source: SaMD Regulation in India (Freyr) <https://www.freyrsolutions.com/blog/samd-regulation-in-india-cdsco-classification-class-a-d-registration-requirements-emerging-market-strategy> — Note: Freyr text: 'Class A requires online registration only; Class B requires state licensing authority approval and may require notified body audit'. Exemption for non-sterile non-measuring Class A came via 2022 amendment (memory).

## Notified bodies
- **[likely] F56** TUV Rheinland India is among the notified bodies registered with CDSCO to audit Class A/B manufacturers; CDSCO publishes the list via public notices.  
  Source: TUV Rheinland India approved as a notified body by CDSCO (TUV Insights) <https://insights.tuv.com/blog/tüv-rheinland-india-approved-as-a-notified-body-by-cdsco-india> — Note: Count of registered notified bodies not captured.

## Licence retention
- **[likely] F57** MDR 2017 licences are perpetual but require a retention fee every 5 years; CDSCO has reminded firms to pay to keep MD-5/MD-9 licences valid.  
  Source: CDSCO calls for medical device firms to pay retention fee (Digital Health News) <https://www.digitalhealthnews.com/cdsco-reminds-medical-device-cos-to-complete-retention-fee-to-keep-licenses-valid> — Note: Retention amount equals original licence fee (memory).
